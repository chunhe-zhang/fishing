# 静湖垂钓

写实风格的湖边钓鱼网页游戏，专门按手机竖屏设计（横屏和电脑也能玩）。傍晚的湖面，站在木栈桥上甩竿。

在线玩：https://chunhe-zhang.github.io/fishing/

## 玩法

1. **抛竿**：按住底部大按钮蓄力，松手抛出去；左右滑动屏幕换方向。
2. **看漂**：镜头会拉近对准浮漂。浮漂点一两下是试口，别急。
3. **提竿**：浮漂被整个拖下水、按钮变红、手机一震时，点一下。点得快是「完美提竿」：鱼更好遛，金币 ×1.2。
4. **遛鱼**：按住收线，松手放线，把拉力保持在绿色区间里，下方能看到鱼的体力。鱼跳出水面时一定要松手，不然线会崩。
5. **上鱼**：显示鱼名、星级、重量（斤）和体长。收下换金币，放生拿一半金币外加「福气」（稀有鱼更爱来）。连续上鱼有连杆加成。

## 模式和奖励

- **休闲垂钓**：慢慢钓，鱼换金币，攒经验升级（新手钓客 → 一代钓王）。
- **限时赛**：3 分钟比总重量，记录最好成绩，按成绩发金币。
- **今日任务**：每天三项（钓几条某种鱼、钓一条大鱼、完美提竿、放生……），做完领金币。
- **三个钓点**：黄昏静湖；清晨薄雾（3 级解锁）；月夜星湖（5 级解锁，有星空、月光和萤火虫）。不同时段鱼不一样。
- **渔具店**：四档鱼竿（收线更快、鱼劲更小）、四档鱼线（更难拉断）、特饵（酒米出大鱼、蚕蛹招稀有鱼、活泥鳅钓猛鱼）、打窝料（接下来 5 竿鱼来得快、个头大）。
- **图鉴**：13 种鱼，没钓到的会给提示。除了常见淡水鱼，还有夜里出来的鲶鱼、稀有的鳜鱼和青鱼，以及传说中的金鲤和月光鳜。
- **意外收获**：偶尔会钓上旧胶鞋、漂流瓶，运气好能钓到小宝箱。

进度（金币、等级、装备、图鉴）存在浏览器里。

## 运行

不需要安装任何东西，用任意静态服务器打开 `index.html` 即可（不能直接双击文件打开），例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

- `index.html`：主页面，使用仓库里自带的 three.js（`vendor/three/`），不依赖外网 CDN，国内服务器也能用。
- `game.html`：同一个游戏的 Claude 网页版本，从 jsDelivr 载入 three.js。

部署到 GitHub Pages：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。

three.js 使用 MIT 许可（见 `vendor/three/LICENSE`）。
