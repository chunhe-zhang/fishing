# 静湖垂钓

写实风格的湖边钓鱼网页游戏，专门按手机竖屏设计（横屏和电脑也能玩）。傍晚的湖面，站在木栈桥上甩竿。

## 玩法

1. **抛竿**：按住底部大按钮蓄力，松手抛出去；左右滑动屏幕换方向。
2. **看漂**：镜头会拉近对准浮漂。浮漂点一两下是试口，别急。
3. **提竿**：浮漂被整个拖下水、按钮变红、手机一震时，点一下。
4. **遛鱼**：按住收线，松手放线，把拉力保持在绿色区间里。拉太猛线会断，太松鱼会脱钩。
5. **上鱼**：显示鱼名、重量（斤）和体长，可以放生或放进鱼护。

十种淡水鱼：鲫鱼、鲤鱼、草鱼、鲢鱼、鳊鱼、罗非鱼、翘嘴、黑鱼，稀有的鳜鱼和青鱼。四种鱼饵（蚯蚓、面饵、玉米、活虾）各招不同的鱼。鱼护记着每种鱼的条数和最大的一条（存在浏览器里）。

## 运行

不需要安装任何东西，用任意静态服务器打开 `index.html` 即可（不能直接双击文件打开），例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

- `index.html`：主页面，使用仓库里自带的 three.js（`vendor/three/`），不依赖外网 CDN，国内服务器也能用。
- `game.html`：同一个游戏的 Claude 网页版本，从 jsDelivr 载入 three.js。

部署到 GitHub Pages：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。

three.js 使用 MIT 许可（见 `vendor/three/LICENSE`）。
